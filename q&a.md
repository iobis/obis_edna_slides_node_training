# Q&A OBIS Node DNA-derived data training

Questions and answers that came up during the two sessions of the OBIS Node DNA-derived data training on Thursday 2 July 2026.

### Why is information from DNA extraction such as concentration of DNA important? What does this information bring?

> **Answer**: The amount of extracted DNA tells you something about the quality of the sample and the extraction. With very little DNA, something might have gone wrong in the sampling or laboratory process. Later, the amount of DNA sequences for an organism (read abundance) can be compared to the total number of DNA sequenced (total read abundance) and the concentration of DNA before sequencing. Again, it then tells you something about the quality of the data along the workflow. A lower taxon richness could then e.g. be explained by this lower amount of DNA.

### In which [original data-submitter] file is DNA specific information provided like primer?

> **Answer**: If your project only uses one primer pair and thus one barcode, this information is often just given in the textual methods paragraph. If the project uses multiple primer pairs and genetic markers, it can be given in a metadata tab of your OTU/ASV table or Taxonomy table. For each taxon, it should then specify the primer pair it was detected with.

### Even when multiple primer pairs are used, is only a single OTU/ASV table generated, with taxa identified by different primer pairs merged in such a way that duplicate taxa do not appear multiple times?

Cont: We received an inquiry regarding how to handle cases where primers designed for different target groups (e.g., fish-specific and benthos-specific primers) both recover information from the same taxonomic group, such as amphibians. If amphibian sequences are detected by both primer sets, how should these records be represented and managed in the OTU/ASV and taxonomy tables?

> **Answer**: In that case the identifications should not be aggregated by taxonomic name for submitting the dataset. In the occurrence table, they should be kept separate where each taxon has the corresponding DNA sequence and the corresponding primers. When different primers are used, the sequence will be different even with the same taxon. We want to keep that granularity in the data submission.

### Is the transformation [from original data files to DwC-A] autogenerated? If yes, do we have OBIS software to input the data

> **Answer**: There are some tools that exist. The best known is the GBIF Metabarcoding Data Toolkit which is easy to use. However, this only works for occurrence core structure.
You can also record the primer information only once. If your study uses multiple primer pairs, you have to record them as different datasets. It works well for a simple dataset structure, but if you have larger datasets it is better to develop your own transformation pipeline.

> There are some additional tools. NOAA developed the edna2obis pipeline: <https://github.com/aomlomics/edna2obis>. The FAIRe project developed multiple tools & R scripts: <https://fair-edna.github.io/download.html>. The OBIS PacMAN pipeline also has a final step to transform bioinformatic outputs into DwC-A: <https://github.com/iobis/PacMAN-pipeline>

### What should be the value for occurrenceStatus for the 0’s in OTU/ASV table? (As this does not mean absent)

> **Answer**: We recommend that you leave them out of the occurrence file, and only record presences.
